# Haraj Profit Opportunity Scraper

أداة متقدمة لاصطياد واستكشاف فرص ربح من موقع حراج (https://haraj.com.sa/) باستخدام Firecrawl.

## الميزات 🚀

- **اصطياد ذكي**: استخدام Firecrawl API للحصول على بيانات دقيقة من حراج
- **تحليل الفرص**: خوارزميات متقدمة لتحديد أشياء يمكن شراؤها وإعادة بيعها برابح
- **تتبع الأسعار**: حفظ سجل كامل لتطور الأسعار لكل فئة
- **إحصائيات السوق**: تحليل بيانات السوق لكل فئة (متوسط - أدنى - أعلى أسعار)
- **تقارير ذكية**: تقارير مفصلة عن أفضل الفرص المتاحة
- **قاعدة بيانات محلية**: تخزين آمن في SQLite مع فهرسة كاملة
- **جدولة تلقائية**: تشغيل مستمر على فترات زمنية قابلة للتخصيص

## المتطلبات 📋

- Node.js >= 18.0.0
- npm أو yarn
- مفتاح API من Firecrawl (احصل عليه من https://www.firecrawl.dev/)

## التثبيت ⚙️

```bash
# استنساخ المستودع
git clone <repository-url>

# تثبيت المتعلقات

# نسخ ملف الإعدادات
cp .env.example .env

# تحرير .env وإضافة مفتاح Firecrawl
```

## الإعدادات ⚙️

أنشئ ملف `.env` في جذر المشروع:

```env
# مفتاح API من Firecrawl
FIRECRAWL_API_KEY=your_api_key_here

# إعدادات التطبيق
NODE_ENV=development
LOG_LEVEL=info

# إعدادات الاصطياد
SCRAPE_INTERVAL=3600000      # 1 ساعة بالميلي ثانية
PROFIT_THRESHOLD=20           # الحد الأدنى لنسبة الربح (%)
MIN_PRICE=50                  # السعر الأدنى بالريال
MAX_PRICE=5000               # السعر الأعلى بالريال

# قاعدة البيانات
DB_PATH=./haraj_listings.db

# الفئات المراد مراقبتها
MONITORED_CATEGORIES=electronics,furniture,cars,clothes,books
```

## كيفية عمل الأداة 🔍

### 1. الاصطياد (Scraping)

الأداة تصطاد الإعلانات من حراج في الفئات المحددة:
- إلكترونيات
- أثاث
- سيارات
- ملابس
- كتب
- رياضة
- أجهزة كهربائية
- هواتف نقالة

لكل فئة، يتم اصطياد عدة صفحات من الإعلانات مع استخراج:
- العنوان
- السعر
- الوصف
- الموقع
- بيانات البائع
- الصور

### 2. تخزين البيانات

البيانات تُحفظ في قاعدة بيانات SQLite محلية بـ 3 جداول:
- **listings**: الإعلانات المصطادة
- **opportunities**: فرص الربح المكتشفة
- **price_history**: سجل الأسعار لكل فئة

### 3. التحليل والمعالجة

الخوارزمية تحلل كل إعلان بناءً على:
- **مضاعف السوق**: نسبة إعادة البيع لكل فئة
- **تحليل الأسعار**: مقارنة السعر بمتوسط السوق
- **الكشف عن الحالات الشاذة**: تحديد الأسعار المنخفضة غير الطبيعية
- **تقلبية السوق**: تحليل استقرار الأسعار
- **نسبة الربح**: حساب الربح المحتمل

### 4. تصنيف الثقة (Confidence Score)

لكل فرصة، يتم حساب درجة ثقة من 0-100 بناءً على:
- دقة بيانات السوق (عدد الحسابات)
- استقرار الأسعار
- مستوى الخصم
- هامش الربح
- جودة الوصف

### 5. التقارير

التقارير تشمل:
- أفضل الفرص حسب نسبة الربح
- أفضل الفرص حسب الربح المطلق
- الفرص الموثوقة جداً (80%+ ثقة)
- إحصائيات قاعدة البيانات

## معلومات تقنية 🔧
